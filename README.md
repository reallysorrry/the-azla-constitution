CORE DESIGN

- The website must be 100% non-scrollable.

- Everything must fit within the viewport.

- Navigation happens entirely through buttons/interactions, not scrolling.

- Make it feel like a custom interactive experience, NOT a generic AI-generated apology website.

- Use sophisticated animations, transitions, micro-interactions, polished typography, depth, and cinematic UI.

- The aesthetic should feel like a mixture of a formal constitution, courtroom case file, interactive game, and personal apology.

- Make it feel intentionally designed and personal.

- Do NOT use generic gradients, generic cards, boring templates, or unnecessary sections.

- Every screen should have a clear purpose.

- Make transitions between screens smooth and satisfying.
